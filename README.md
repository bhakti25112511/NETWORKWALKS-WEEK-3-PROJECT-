NETWORKWALKS – WEEK 03 PROJECT

Password Security & Hash Analysis

Cybersecurity & Ethical Hacking Training | Networkwalks

This repository showcases my practical work completed during Week 03 of the Cybersecurity and Ethical Hacking Training program. The activities focused on password hash extraction, dictionary-based password auditing, and understanding password security using different cybersecurity tools.

The practical sessions provided exposure to password auditing techniques and demonstrated the importance of creating strong and secure passwords.

---

🎯 Learning Objectives

- Understand password hashing and its application in authentication.
- Learn the difference between hashing and encryption.
- Explore password hash extraction from protected PDF files.
- Understand dictionary-based password auditing.
- Gain practical knowledge of John the Ripper and Johnny GUI.
- Explore online password auditing utilities provided by Networkwalks.
- Identify the security risks associated with weak passwords.

---

🧪 Practical Modules

Module 1: Password Auditing Using John the Ripper

Tools Used:

- John the Ripper (Jumbo Edition)
- Johnny GUI
- PDF Hash Extractor

Implementation:

1. Installed and configured John the Ripper on Windows.
2. Set up Johnny GUI and connected it with the John the Ripper executable.
3. Extracted the hash information from the assigned protected PDF.
4. Saved the extracted hash into a text file.
5. Imported the hash file into Johnny GUI.
6. Executed the dictionary-based password auditing process.
7. Checked the recovered password against the protected PDF.

Key Learning:

Understood the working process of John the Ripper and learned how Johnny GUI makes password auditing easier through a graphical interface.

Module 2: Password Auditing Using Networkwalks Tools

Tools Used:

- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

Implementation:

1. Opened the Networkwalks Hash Calculator in a web browser.
2. Used the assigned PDF file for hash extraction.
3. Retrieved and copied the generated hash value.
4. Accessed the Networkwalks Password Cracker.
5. Entered the extracted hash into the tool.
6. Performed dictionary-based password testing.
7. Observed the output and verified the result using the PDF.

Key Learning:

Explored browser-based password auditing tools and understood the workflow involved in hash extraction and password recovery.

🔍 Technical Concepts

Concept| Description
Hashing| Converts data into a fixed-length digest using a hashing algorithm.
Password Hash| A stored hashed representation used for password verification.
Dictionary Attack| Tests possible passwords using a predefined wordlist.
John the Ripper| A tool used for password recovery and security auditing.
Johnny GUI| A graphical interface for operating John the Ripper.
PDF Hash Extraction| Obtaining password hash information from protected PDF documents.
